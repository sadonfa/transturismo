# Transturismo Backend

API REST desarrollada con **Django** y **Django REST Framework** para la gestión y reservas de Transturismo Cartagena.

---

## 🚀 Requisitos del Sistema
* Python 3.10+
* MySQL / MariaDB
* Servidor Nginx y Gunicorn (Entorno de Producción)
